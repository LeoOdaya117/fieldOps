# PSGC reference data (Q2 2026)

This directory contains the region, province, municipality, and city subset of the Philippine Statistics Authority's Q2 2026 Philippine Standard Geographic Code publication (reference date: 30 June 2026). Barangays and sub-municipalities are intentionally excluded.

- Official publication: https://psa.gov.ph/classification/psgc
- Official data file: https://psa.gov.ph/system/files/scd/PSGC-2Q-2026-Publication-Datafile.xlsx
- Normalized source mirror: `psgc` Python package version `2026.4.13.0`, based on the official Q1 2026 data
- Q2 adjustments applied from the PSA publication notes: San Isidro, Davao del Norte is named Sawata; Don Victoriano Chiongbian, Misamis Occidental is named Don Victoriano
- Normalization: independent and highly urbanized cities have a null province relationship; only `City` and `Mun` geographic levels are included

The JSON payload is sorted by PSGC code and is imported idempotently by `PsgcReferenceSeeder`. Its SHA-256 checksum is recorded in `database/data/psgc-q2-2026.sha256` and in the `psgc_reference_releases` table after import.
