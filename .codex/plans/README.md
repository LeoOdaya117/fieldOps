# Saved Feature Plans

`$feature-plan` writes one new Markdown plan per request here using `YYYY-MM-DD-<short-feature-slug>.md`. If the name already exists, it adds a numeric suffix instead of overwriting the earlier plan.

`$feature-build` updates the selected plan's status, progress, and observed verification while preserving its original goal and acceptance criteria. Keep completed plans as project history; do not recycle a prior plan file for a new feature.
